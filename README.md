# Diplom_3

UI автотесты для веб-приложения Stellar Burgers.

## Стек

- Python 3.13
- pytest
- Selenium
- Allure

## Структура проекта

```
helpers/
locators/
pages/
tests/
```

## Запуск тестов

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск тестов:

```bash
pytest
```

Запуск с Allure:

```bash
pytest --alluredir=allure-results
allure serve allure-results
```

## Проверки

### Основная функциональность

- переход в «Конструктор»;
- переход в «Лента заказов»;
- открытие модального окна ингредиента;
- закрытие модального окна;
- увеличение счётчика ингредиента.

### Лента заказов

- увеличение счётчика «Выполнено за всё время»;
- увеличение счётчика «Выполнено за сегодня»;
- появление номера заказа в разделе «В работе».

Тесты запускаются в Google Chrome и Mozilla Firefox.
